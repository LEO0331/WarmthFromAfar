# WanderStamp Docs

This folder provides a quick project map for development and maintenance.

## Documents

- `flow.md`: request/track/receive and admin workflow maps.
- `info.md`: architecture, folder structure, data model, and testing notes.
- `system-design-deep-dive.md`: architecture decisions, tradeoffs, data-structure alternatives, and deep-dive Q&A prep.
- `system-design-deep-dive.zh-TW.md`: stakeholder meeting version in Traditional Chinese with the same deep-dive structure.

## Quick Start

```bash
flutter pub get
flutter analyze
flutter test
flutter run -d chrome
```

## Scope

These docs are implementation-facing and complement the project-level README.
